# Agile Project Management – Sella Platform

## Overview

Sella is a proposed digital platform designed to connect entrepreneurs with investors through a more structured and efficient investment-matching process.

This academic group project focused on planning and managing the Sella platform using **Agile project management and the Scrum framework**.

**My Role:** Agile Project Lead

## Key Deliverables

* Project Charter
* Requirements Analysis
* Scope Statement
* Work Breakdown Structure (WBS)
* WBS Dictionary
* RACI Chart
* Gantt Chart
* Risk Register
* Final Project Report
* Project Presentation

## Methodology

The project followed the **Agile Software Development Life Cycle (SDLC)** using the **Scrum framework**, with the platform planned across four development sprints.

## My Contribution

As the **Agile Project Lead**, I contributed to project planning and management activities, including project charter development, scope definition, sprint planning, project documentation, and coordination of project deliverables.
